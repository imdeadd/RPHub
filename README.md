# RPHub – Automatyczny system sklepu dla FiveM i Discord

**RPHub** to kompleksowa platforma e-commerce dla serwerów FiveM i Discord, która automatyzuje sprzedaż VIP, rang, itemów i ról.

## 🚀 Funkcje

- **Automatyczne role Discord** – Nadawanie ról natychmiast po płatności
- **Integracja z FiveM** – Wysyłanie itemów, pieniędzy i prac bezpośrednio do graczy (QBCore i ESX)
- **Płatności Stripe** – Karty, BLIK, Przelewy24
- **Panel administratora** – Zarządzanie serwerami, produktami i statystyki sprzedaży
- **Bot Discord** – Sprawdzanie statystyk i zakupów użytkowników
- **Zabezpieczenie webhooków** – Ochrona przed duplikacjami
- **Generator kluczy API** – Bezpieczna autoryzacja skryptów FiveM

## 🛠️ Technologie

- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB
- **Płatności:** Stripe API
- **Integracje:** Discord API, FiveM
